    Your companion key: copy it now, it is not shown again.
  2. In a terminal, add the marketplace and install the plugin (safe to run again): 
    claude plugin marketplace add EaseIT-cz/vornik
claude plugin install vornik-companion@vornik
  3. When Claude Code enables the plugin it asks for two values. Give it this instance's address, {{.VornikURL}}, and the key from step 1. Claude Code keeps the key in your system's credential store, not in a file or your shell history.
