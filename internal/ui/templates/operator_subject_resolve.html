Search

The subject's recorded name is always searched. Add up to five other names (a nickname, a former name), 3–100 characters each. The free-text search is lexical: it finds the literal name in stored memory records, case-insensitively, including records recall would not return (refuted, superseded, expired). It does not find pronouns, relationships ("my sister"), misspellings, or text in uploaded files and conversation transcripts. Records under an active Art 18 restriction are not searched.{{if .IsRestriction}} For this restriction request: a record that mentions this subject but is already restricted through ANOTHER subject is not proposed, so this restriction cannot be widened to it here.{{end}}

Stored memory records containing a searched name, newest first, at most 50. Each shows only the text around the first match. Rejecting records your decision in the audit log only; the record will be proposed again by a later search.
